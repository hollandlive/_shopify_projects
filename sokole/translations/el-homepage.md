Footer link lists are rich text with hardcoded `href="/collections/..."`. In the Greek version use
`/el/collections/...`, `/el/pages/contact`, `/el/account`, `/el/products/gift-card`, otherwise the
links send Greek visitors back to the English site.

Ready-to-paste Greek HTML for the Shop column:

```html
<ul><li><a href="/el/collections/perfume-for-her">Αρώματα για εκείνη</a></li><li><a href="/el/collections/perfume-for-him">Αρώματα για εκείνον</a></li><li><a href="/el/collections/premium-boxes">Πολυτελή κουτιά δώρου</a></li><li><a href="/el/collections/body-mist-fragrance">Body Mist</a></li><li><a href="/el/products/gift-card">Δωροκάρτες</a></li></ul>
```
