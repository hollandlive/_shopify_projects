# Магазин для клиента на Shopify — как делать правильно

Урок Sokole (2026): магазин был создан как **Development store** прямо в админке. Его нельзя ни передать клиенту, ни перевести на платный тариф, ни снять с него пароль. В итоге пришлось переносить сайт в новый магазин. Чтобы так не было, делай по шагам ниже.

## 0. Один раз: подготовить свой аккаунт
1. Shopify-аккаунт (dutchnewsru@gmail.com): **заполнить имя и фамилию** на accounts.shopify.com. Без них collaborator-вход и CLI молча не работают («Account missing first and last name»).
2. **Partner / Dev Dashboard** (dev.shopify.com): пройти **Verify identity** (паспорт + селфи, ~5 минут). Без этого нельзя запросить доступ к магазину клиента.

## 1. Выбрать путь ДО начала работы
Спроси себя: кто будет владельцем и платить за Shopify? Почти всегда — клиент. Тогда только один из двух вариантов:

### Вариант A (рекомендуется): Client transfer store
1. dev.shopify.com → **Stores → Create store** → тип **Client transfer store** (НЕ «Development store»).
   - Проверка: в карточке магазина / Settings → Plan должно быть видно, что это **client transfer**, а не «Development store».
2. Строишь весь сайт там: тема, товары, коллекции, языки, рынки, доставка, страницы.
   - Пока магазин твой: пароль не снимается, реальные оплаты не работают, **Shopify Payments не включать** (с активными Payments/Balance/Capital передать нельзя), только бесплатные приложения.
3. Когда клиент заплатил: Dev Dashboard → магазин → **Transfer ownership** → email клиента.
4. Клиент принимает письмо → **сам выбирает тариф** → подключает Shopify Payments → тестовый заказ → снимает пароль.
5. Ты остаёшься collaborator'ом (для поддержки), если клиент не удалит.

### Вариант B: клиент сам создаёт магазин
1. Клиент регистрируется на shopify.com на свой email, страна, сразу выбирает тариф.
2. Клиент даёт тебе **collaborator request code**: Settings → Users → Security.
3. Ты: dev.shopify.com → Stores → **Request store access** → URL магазина + код + Select all → Request access. Клиент одобряет.
4. Вход только через Dev Dashboard → магазин → **Log in**.
5. Минус: работаешь в чужом магазине с первого дня; плюс: передавать ничего не нужно.

**Никогда** не создавать обычный Development store для клиентского сайта — он только для тестов тем/приложений.

## 2. Сразу при создании магазина
- Язык по умолчанию — **English** (Settings → Languages), потом добавить греческий/другой. Если страна Greece, Shopify сам ставит греческий по умолчанию → меню, тарифы доставки, страницы создаются на греческом.
- Проверить названия меню, тарифов доставки и рынков — переименовать на английский.

## 3. Домен
- DNS у регистратора (Papaki и т.п.): A `@` → `23.227.38.65`, CNAME `www` → `shops.myshopify.com`. MX не трогать.
- Settings → Domains → **Connect existing**. Пароль регистратора вводит только сам Артём / клиент.
- Если домен был на другом магазине: там сначала сделать primary `*.myshopify.com`, потом удалить домен, и только потом подключать к новому.

## 4. Перенос между магазинами (если всё же понадобится)
- Тема: `shopify theme pull` из старого → `shopify theme push --unpublished --store <new>`; картинки в `assets/` переезжают вместе с темой.
- Товары: Products → Export (CSV) → Import в новый; подарочную карту создать вручную (CSV её не импортирует).
- Коллекции, меню, страницы, рынки, доставка — вручную.
- Переводы: экспорт CSV из **нового** магазина (ID другие!) → подставить переводы по английскому тексту (`sokole/migration/map_translations.py`) → Import с галочкой overwrite. Тему перед экспортом опубликовать, иначе её строк нет в CSV.

## 5. Деньги
Передавать магазин (Transfer ownership) только после полной оплаты.
